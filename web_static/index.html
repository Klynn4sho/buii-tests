Server configuration

Configuration

The same settings behind /setlog, /setalertrole, /setmodrole, /setprefix and the /setmusic* commands — changes here update the exact same database rows those commands do.

#

Prefix

Text-command prefix

The prefix used for text commands, e.g. b,leaderboard. Slash commands always work regardless.

Join log channel

—

Where join-risk alerts get posted. Falls back to a channel literally named #welcome if unset.

—

Music channel

—

Restricts music-link detection to one channel. Leave unset to allow any channel.

Music ping role

—

Pinged whenever a new song is posted for rating.

⏱

Post-song channel lock

—

Seconds the music channel locks after a song is posted. 0 disables the lock.
